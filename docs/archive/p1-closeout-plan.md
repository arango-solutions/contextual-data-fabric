# P1 Close-Out Record

> **Completed 2026-08-04.** The credible-demo gap is closed. The engine now
> federates four live source kinds — Ontop/Postgres, native Snowflake, native
> ClickHouse, and arango-sparql-py/ArangoDB — over r2g/analyzer-emitted mappings
> and a deterministic `account_id` join spine. The HTTP service, browser demo,
> NL-to-SPARQL seam, provenance UI, and 15-case live golden gate are all landed.
>
> The locked demo arc is the **five-question** sequence **Q7 → Q2 → Q9 → Q5 →
> Q8**, with **Q2** (renewal risk + WHY) as the lead cross-source question.
> Three adversarial cases lock empty/refusal behavior. The retired sentiment
> centerpiece and its extraction requirement are no longer part of the product
> or acceptance scope.
>
> Runtime fuzzy entity matching remains explicitly deferred to P2/P3 M6. P1
> uses the locked document-level join:
> `Chunk → Document.account_id ↔ Account`.

**Accept:** a Q2-shaped query for Meridian returns rows joined on `account_id`; the retrieval path shows the seeded key in the Arango leg's query; no leg returns unbounded rows.

   policy and user-identity model.

   of truth; local, ignored research files are never a runtime dependency.

> **Completed 2026-07-22.** The locked source-system inventory says usage

> the same r2g R2RML straight to Snowflake SQL over `snowflake-connector-python`.

> sidesteps the JDBC/Arrow/Java-17 quirk. WP-S3's concept-ownership split is

> landed 2026-07-22 (dialect proven vs a fake transport; live test env-gated).
